# Documentation

A quick map of what's in here.

## Using WebSquared

- **[USAGE.md](USAGE.md)**, how to use every feature: tabs, bookmarks,
  history, private browsing, search engines, and the settings panel.

## Running your own instance

- **[DEPLOY.md](DEPLOY.md)**, self-hosting guide: installing, building,
  running under PM2, putting it on the internet, and auto-deploying on push.

## Understanding how it works

- **[ARCHITECTURE.md](ARCHITECTURE.md)**, how a request actually flows
  through the system, the URL-rewriting scheme, and the reasoning behind
  the trickier parts of the codebase.

## Contributing

- **[CONTRIBUTING.md](CONTRIBUTING.md)**, code style, what a good PR looks
  like, and how automated checks (CI, CodeQL, Dependabot) fit in.

## Policies

- **[SECURITY.md](SECURITY.md)**, what counts as a vulnerability here,
  what doesn't, and how to report one privately.
- **[PRIVACY.md](PRIVACY.md)**, what a running instance can see and what
  it does (and doesn't) do with that.
- **[TERMS.md](TERMS.md)**, terms of service for using a running instance.
- **[CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md)**, expected behavior for
  anyone participating in the project.

All of these are also readable in-app, from Settings > About.
